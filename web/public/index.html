    How it works

    What learners get

    A clean player for video, audio and PDF, or your HTML exactly as you built it. The package tracks completion and progress and remembers where each learner stopped, with a Resume or Start over choice when they come back.

    What your LMS gets

    A zip with imsmanifest.xml at the root, one SCO, and everything inside the package. No external fonts or scripts, so it works offline and inside any LMS frame.

    Where conversion runs

    Files up to about 2 MB are converted on our server and not stored. Larger files are converted in your browser, so they never leave your computer.

    Questions

    Which version should I upload, 2004 or 1.2?

    Use the one your LMS lists in its import settings. If you are unsure, start with SCORM 1.2: almost every LMS supports it. Upload one package per activity, never the bundle zip.

    My HTML uses Google Fonts and the check failed. Why?

    SCORM packages must be self-contained, because many LMSs block outside requests. Embed the font files in your page (or use system fonts) and convert again.

    How is a video marked complete?

    When the learner has actually played the share you chose, 95% by default. Skipping ahead does not count. Turn on "Stop learners skipping ahead" to block it entirely.

    Do I still need to test in my LMS?

    Yes, once. The checks confirm the package is built correctly; one test upload confirms your LMS records completion the way you expect.
